# Reference Genome

The BRCA1/BRCA2 NGS analysis was performed using the human GRCh38/hg38 reference genome.

## Reference

* **Genome build:** GRCh38
* **Reference type:** Human primary assembly
* **Reference file used locally:** `Homo_sapiens.GRCh38.dna.primary_assembly.fa`

The reference genome and associated index files are not included in this repository because of their large file size.

The same GRCh38 reference build was used for read alignment, variant analysis, and VEP annotation.
